# Polyglot Quest

Mobile-first, audio-first language learning for Polish speakers — **Spanish, German and Japanese from zero**.

> Work in progress — see [PROJECT_PLAN.md](PROJECT_PLAN.md) for the current milestone status.

## Quick start

```bash
npm install
npm run dev        # http://localhost:5173
npm run check      # lint + type check + unit tests + production build
```

More documentation (installation, Android build, methodology, content sources) is added as the
milestones are completed.
